# Fair peer-evaluation checklist

Evaluate only the group assigned by the instructor. Record evidence and constructive
feedback; use the instructor's scoring scheme. Do not invent a group or outcome.

- [ ] Installation instructions work and dependencies are clear.
- [ ] Sample counts are correct; test repeated words, case, and punctuation.
- [ ] Chunking preserves tokens and handles more chunks than words.
- [ ] Mapper, shuffle, and reducer outputs are visible and consistent.
- [ ] Final totals and chart agree with the output table.
- [ ] Local multiprocessing and its timing limitations are explained honestly.
- [ ] Empty input and invalid files receive useful messages.
- [ ] Architecture and source structure are understandable.
- [ ] Tests run and cover meaningful edge cases.
- [ ] Video is below five minutes and demonstrates the application clearly.
